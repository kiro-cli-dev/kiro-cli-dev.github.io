# Kiro Field Notes

Kiro CLI installs with a single curl command and is pitched at specs rather than autocomplete. This page covers what that means in practice and what the site leaves unsaid.

**Read the full page:** https://kiro-cli-dev.github.io/

Kiro is built for engineers who already work in a large repository and want agents that produce a reviewable artifact rather than a wall of diff. Someone whose actual problem is getting a first version of a site or a small app on screen will find the specs-and-hooks framing heavier than the job requires. The caveat: this is an AWS property, the sign-in path runs through app.kiro.dev, and the landing page mentions a starter credit for a paid plan without stating what the plans cost. If you want output in minutes and no toolchain at all, Begin.sh is the honest comparison at the other end of the scale.
